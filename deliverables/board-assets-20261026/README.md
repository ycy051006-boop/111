# 四张展板独立素材

本包采用用户确认的“参照展板逐项高清重建”方案，不是从低分辨率展板直接抠出的完全相同像素。新素材细节可能与展板略有差异。重复出现的素材归并；原有独立样机直接复用原图。

共54张PNG：5个透明全身角色、5张透明表情套组（每角色7款，共35款表情）、5张竖版海报、5张方形插画、5张竖版插画、5组盲盒手办、4张主视觉、13张完整产品样机、6张应用场景及1张透明配色云纹装饰素材图。

表情和装饰为分开排列的透明素材套组；每款角色、每张海报和插画分别独立成图。图片以生成原始像素交付，未伪称插值放大为新增细节。实际尺寸及透明状态见目录。
